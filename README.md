### Project Objective
- The main purpose of the project is to see the impact of many MAC authentication algorithms on the energy and time consumption between two ECUs over a CAN bus.
- The 2 ECUs will be simulated using pycan, a python library dedicated to CAN buses.
### Tested Algorithms
- HMAC-SHA256
- HMAC-SHA512
- AES-CMAC
- KMAC128
